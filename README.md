# voice-lab

Интерактивный explainer конвейера голосового агента. Говоришь фразу — видишь, как
она проходит захват → VAD → STT → LLM → TTS → воспроизведение: реальные миллисекунды
каждой стадии, их перекрытие, и персонаж, артикулирующий ответ по таймстемпам от TTS.

Живая версия: https://unimatch-hiring.github.io/voice-lab/

## Запуск

```sh
npm ci
npm run dev     # http://localhost:5173
```

Публичная сборка работает в офлайн-режиме на записанных фикстурах — весь конвейер
и сцена работают без ключей. Живой микрофон требует развёрнутого Worker'а
(`worker/`) и переменных сборки `VITE_WORKER_URL`/`VITE_VIBE_TOKEN`.

`VITE_WORKER_URL` прописан в переменных репозитория и уезжает в бандл: адрес
Worker'а не секрет, доступ к нему закрывают список origin и токен. А вот
`VITE_VIBE_TOKEN` в публичной сборке отсутствует намеренно — он расходует платную
квоту, поэтому подставляется локально:

```sh
VITE_VIBE_TOKEN=<токен> npm run dev
```

## Как это устроено

- `src/lib/pipeline/` — стадии конвейера, каждая с узким интерфейсом.
- `src/lib/pipeline/orchestrator.ts` — прогон turn'а, сбор метрик, поток событий.
- `src/scene/` — сцена. Читает только поток событий и не знает, как работает пайплайн.
- `worker/` — Cloudflare Worker, выдающий одноразовые токены (аудио через него не идёт).
