# Behavioral test cases

Each automated history test includes one case ID in its name. The app integration tests run in jsdom with simulated ElevenLabs callbacks and a real local history API. History component tests simulate API outcomes. Queue unit tests exercise browser storage, simulate storage failures and observe which writes are delivered. The HTTP and store tests use temporary data directories. See the [history diagrams](../docs/history.md) for the components and request flow.
